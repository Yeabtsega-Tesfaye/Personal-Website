# Contributing Guide

Thank you for your interest in contributing to this project.

This portfolio website is continuously evolving as part of my frontend engineering and software development journey. Contributions, suggestions, bug reports, and improvements are always appreciated.

---

# Ways to Contribute

You can contribute by:

* Reporting bugs or UI inconsistencies
* Suggesting performance improvements
* Improving accessibility
* Enhancing responsiveness across devices
* Refactoring frontend structure
* Improving animations or interactions
* Suggesting better project organization
* Improving documentation

---

# Getting Started

## 1. Fork the Repository

Create your own fork of the project.

## 2. Clone the Repository

```bash
git clone https://github.com/your-username/Personal-Website.git
```

## 3. Navigate Into the Project

```bash
cd Personal-Website
```

## 4. Open the Project

Open the project in your preferred editor such as VS Code.

---

# Development Guidelines

Please try to follow these principles when contributing:

* Keep code clean and readable
* Maintain responsive design consistency
* Avoid unnecessary dependencies
* Preserve visual and architectural consistency
* Write meaningful commit messages
* Test changes before submitting pull requests

---

# Commit Message Examples

Good commit messages:

```bash
Add responsive navbar animation
Improve hero section spacing
Fix mobile overflow issue
Refactor skill grid layout
```

Avoid vague commit messages like:

```bash
update
fix stuff
new changes
```

---

# Pull Request Process

1. Create a new branch for your feature or fix
2. Make your changes
3. Test the project locally
4. Commit with clear messages
5. Open a pull request with a short explanation
